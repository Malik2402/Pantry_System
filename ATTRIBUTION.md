# App artwork

The current chef-hat and cutlery logo is the image supplied by the user as `1.jpeg`. The original JPEG is included unchanged as `chef_logo.jpg`. No creator or licence information was supplied with this image.

The previous recipe-book logo is no longer included in this version.

The Home header wallpaper is the image supplied by the user as `2.jpeg`, included unchanged as `home_wallpaper.jpg`. No creator or licence information was supplied with this image.

The 40 recipe photos and 45 ingredient photos were supplied by the user in `pantry images.zip`. Their original image bytes are included unchanged. Although the supplied filenames ended in `.jpg`, their actual format is WebP; the app uses the correct `.webp` extension. No creator or licence information was supplied with these photos.
